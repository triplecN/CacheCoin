CacheCoin (CCCN) - START HERE
============================

New to CacheCoin and not a programmer? Read docs\BEGINNER_GUIDE.md first:
step-by-step instructions in plain English, including backups and private keys.

CacheCoin is a small, Tor-only cryptocurrency. This folder runs a full node,
and optionally mines on your CPU.

1. Double-click CacheCoin.cmd
2. Choose "Node only" unless you want to mine. Mining is a lottery: you may
   find a block, you may not. There is no guaranteed reward.
3. The first start can take a few minutes; the node syncs over Tor.
4. Your data lives in %APPDATA%\CacheCoin. The log is in logs\launcher.log.
5. To stop a node that this launcher started: right-click the tray icon and
   choose "Stop CacheCoin". If the launcher attached to a node that was already
   running, the tray leaves it running; use CacheCoin.cmd -Stop for that.
   Closing the window can leave the node running (the next start attaches).
6. If the node runs automatically at login (hidden: no window, no tray), stop
   it with: CacheCoin.cmd -Stop
   To stop it starting at login at all: CacheCoin.cmd -DisableAutostart
7. Never delete the data folder while the node is running.
8. Mining starts only after you save and confirm a backup (see BACKUP.txt).
   Until then, an automatic start keeps the node running but does not mine.
   The wallet is checked before mining; if it changed or the backup does not
   cover it, mining waits for a new backup.

Tor is required. If Tor is not already running, the bundled copy starts
automatically. If mining, you MUST save a backup first; see docs\BACKUP.txt.
